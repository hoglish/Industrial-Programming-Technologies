## Организация кода

- **`task-service.js`**: содержит чистую бизнес-логику (создание, поиск, изменение статуса, удаление задач). Не зависит от DOM. Возвращает объекты `{ ok: true, tasks }` или `{ ok: false, error }`.
- **`task-selectors.js`**: отвечает только за вычисление видимой выборки по фильтру статуса и приоритета. Не изменяет исходные данные.
- **`task-view.js`**: создаёт DOM-элементы карточек, обновляет список, сводку и сообщение о пустом состоянии. Использует `replaceChildren` для безопасной замены содержимого без потери обработчиков контейнера.
- **`main.js`**: хранит состояние приложения (`currentTasks`, `currentFilter`, `currentPriority`). Содержит обработчики событий с делегированием, вызывает сервисные функции и инициирует перерисовку через `renderApp()`.

Полный список хранится в переменной `currentTasks` в `main.js`. Фильтры хранятся отдельно. События обрабатываются в `handleTaskListClick`, `handleFilterClick`, `handlePriorityClick`. Сводка вычисляется в `renderSummary` через импорт `getTaskStats` из сервиса.

## Отладка и клавиатура

**Точка останова:** строка чтения `dataset.taskId` в `handleTaskListClick`.
- `event.target`: `<span class="action-label">Выполнена</span>` (клик по тексту внутри кнопки)
- `event.currentTarget`: `<ul id="task-list">` (контейнер с обработчиком)
- `dataset.taskId`: `"4"` (строка)
- Числовой `id`: `4` (после `Number()`)
- Действие: `"toggle"`
- Результат сервиса: `{ ok: true, tasks: [...] }`

**Клавиатура:** Tab перемещает фокус между кнопками фильтров и карточками. Enter и Space активируют кнопки. После изменения статуса фокус возвращается на кнопку той же задачи (`restoreTaskFocus`). После удаления — на активный фильтр.

**Отказ:** При ручном изменении `data-task-id` на `777` появляется сообщение «Задача не найдена». При значении `4abc` действие игнорируется, данные сохраняются. Корректный выбор фильтра пересоздаёт карточки из настоящего массива и очищает сообщение.
