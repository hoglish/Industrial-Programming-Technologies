## 4. Задание 2. Типы данных и преобразования
| Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |
| --- | --- | --- | --- | --- |
| `"8" + 2` | "82" | "82" | string | Конкатенация: число приводится к строке. |
| `"8" - 2` | 6 | 6 | number | Математическая операция: строка приводится к числу. |
| `Number("8") + 2` | 10 | 10 | number | Явное приведение строки к числу перед сложением. |
| `"12" > "3"` | true | false | boolean | Посимвольное сравнение строк: код '1' меньше кода '3'. |
| `12 === "12"` | false | false | boolean | Строгое равенство: разные типы данных (number и string). |
| `Number("")` | 0 | 0 | number | Пустая строка при приведении к числу дает 0. |
| `Number("text")` | NaN | NaN | number | Нечисловая строка не может быть преобразована. |
| `Boolean("false")` | false | true | boolean | Любая непустая строка (даже "false") истинна. |
| `typeof null` | object | object | string | Исторический баг JS, null считается объектом. |
| `typeof NaN` | number | number | string | NaN технически относится к типу number. |

## 7. Задание 5. Отладка
**Исходная ошибка 1:** Складывание строк `"3" + "2"` давало `"32"` вместо `5`.
*Исправление:* Добавлено `Number()` перед сложением.
**Исходная ошибка 2:** Цикл `for (let i=1; i<4; i++)` выполнялся только до 3, сумма была 6 вместо 10.
*Исправление:* Изменено условие на `i <= 4`.
